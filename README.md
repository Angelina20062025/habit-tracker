# Веб-приложение «Трекер привычек»

## Описание проекта
Сервис для формирования и отслеживания полезных привычек. Позволяет пользователям создавать индивидуальные цели, настраивать периодичность, вести ежедневный учёт выполнения, а также анализировать прогресс с помощью графиков и календаря. Администратор сервиса осуществляет управление пользователями и ведёт глобальный справочник типовых привычек.
